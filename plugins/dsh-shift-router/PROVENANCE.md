# Provenance

`dsh-shift-router` is an adaptation of
[`green-dalii/pi-shift-router`](https://github.com/green-dalii/pi-shift-router),
not an original plugin of this collection.

The DSH port retains the upstream routing concepts and adds DSH-specific agent
hooks, settings UI, deployment catalog discovery, child-agent classification,
orchestration, and failover behavior. The upstream project and this adaptation
are MIT licensed. The copyright and license notice is preserved in `LICENSE`.

The recovered DSH adaptation did not have a publishable upstream repository to
which this account could write. It is vendored here so its exact reviewed source
can be reproduced without presenting it as independently originated work.
